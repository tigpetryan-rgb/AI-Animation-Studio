# M55 video generation gateway contract

The controlled Android Runtime must never contain a Runway or other provider API key. The APK only receives a non-secret HTTPS gateway URL through the Gradle property `generationApiBaseUrl`; Foundation CI sources that value from the repository variable `AISTUDIO_GENERATION_API_BASE_URL` when provisioned.

## Create a video job

`POST {apiBaseUrl}/v1/video-jobs` uses `multipart/form-data` generated by the browser. Fields:

- `chatId` — Studio chat identity.
- `clientRequestId` — unique client idempotency identity.
- `prompt` — the user prompt.
- one or more `reference` parts — the original uploaded `File` bytes and filenames.

The gateway is responsible for authenticating to the actual video provider with server-side credentials and for idempotently mapping `clientRequestId` to one provider job.

Response JSON must include `jobId` and `status`. Supported status values are `queued`, `running`/`generating`, `processing`, `succeeded`, `failed`, and `cancelled`. Optional `progress` is normalized to `0..1` and is displayed only when supplied by the backend. Optional `pollAfterMs` controls the next poll interval.

## Read a job

`GET {apiBaseUrl}/v1/video-jobs/{jobId}` returns the same status object. A succeeded job must include:

```json
{
  "status": "succeeded",
  "result": {
    "videoUrl": "https://...",
    "downloadUrl": "https://...",
    "mimeType": "video/mp4",
    "fileName": "generated-video.mp4"
  }
}
```

`videoUrl` must be playable by the controlled WebView. `downloadUrl` must be fetchable with CORS so the Studio can pass the resulting blob to the existing native `AIStudioRuntime.saveBlob()` streaming bridge. If `downloadUrl` is omitted, `videoUrl` is used.

## Cancel a job

`POST {apiBaseUrl}/v1/video-jobs/{jobId}/cancel` cancels the provider job when supported. Any 2xx response is treated as a successful cancellation.

## Security and deployment requirements

- Provider credentials stay exclusively on the gateway/server side.
- Production `generationApiBaseUrl` must be HTTPS and contain no embedded credentials, query, or fragment.
- The gateway must explicitly allow the controlled Android asset origin `https://appassets.androidplatform.net` for the required CORS methods and response headers.
- The gateway must not invent progress percentages when the provider does not expose them.
- Signed result URLs may be used; their lifetime must cover preview and save/download.
- The gateway should preserve provider error messages that are safe to show to the user, while never returning secrets.

A Foundation CI success without a provisioned and live `AISTUDIO_GENERATION_API_BASE_URL` proves the client integration and artifact identity, but does **not** qualify M55 as production-generation merge-ready. A real provider-backed end-to-end job from the exact final APK remains required.
